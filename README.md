- **Label**: optimal_rank (1-42)
- **Format**: CSV
- **Size**: ~98 KB

## Features

The dataset contains 28 features for NGS (Next-Generation Sequencing) laboratory scheduling:

### Task Features (8)
1. base_duration - Task processing time (minutes)
2. remaining_ops - Remaining operations count
3. is_critical_path - Critical path indicator (0/1)
4. reagent_type - Reagent type index (0-2)
5. job_priority - Job priority (1-5)
6. heuristic_rank - L2 heuristic ranking
7. task_successor_outdegree - Number of successor tasks
8. dynamic_slack - Dynamic slack time (minutes)

### Machine Features (6)
9. m_queue_len - Machine queue length
10. m_backlog_time - Machine backlog time (minutes)
11. m_setup_needed - Setup time required (minutes)
12. m_utilization_1h - Machine utilization rate (EMA)
13. m_fail_rate_dynamic - Dynamic failure rate
14. m_versatility_score - Machine versatility score

### Resource Features (5)
15. tech_available - Available technicians
16. oper_available - Available operators
17. staff_util_rate - Staff utilization rate
18. tips_inventory - Pipette tips inventory (%)
19. reagent_stock - Reagent stock level

### Environment Features (9)
20. sim_hour_of_day - Current hour (0-23)
21. system_load - Active jobs count
22. batch_sync_gap - Batch synchronization gap
23. normalized_makespan_so_far - Normalized elapsed time
24. task_release_wait_time - Task waiting time (minutes)
25. successor_total_workload - Total successor workload (minutes)
26. job_completion_ratio - Job completion ratio
27. resource_bottleneck_prob - Resource bottleneck probability
28. m_reliability_factor - Machine reliability factor

## Label

- **optimal_rank**: Optimal task ranking (1-42) generated by CP-SAT solver
